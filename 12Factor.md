# 12 Factor - Factores importantes
1. Dependencias: Siento que es un aspecto importante porque evitar tener que instalar las dependencias en la maquina local y evitar posibles problemas entre versiones lo cual es algo demasiado util en el tema de despliegue porque siempre se pueden manejar las mismas dependencias, aqui docker es super importante porque permite encapsular todas las dependencias y tener un entorno controlado que se puede reproducir en distintas maquinas utilizando contenedores
2. Configuracion: Manejar todo utilizando variables de entornos me parece crucial por el hecho de que puedo evitar exponer las credenciales del sistema en la aplicacion pero tengo todo controlado en un solo punto en el que puedo modificar y acceder facilmente y puedo incluso montar un IaC cambiando estas variables de manera mas sencilla
3. Backing services: Este me parece importante porque tambien esta muy relacionado con principios de clean architecture puesto que la idea es evitar acoplar la aplicacion a servicios externos y que estos se puedan intercambiar facilmente sin tener que alterar mucho la aplicacion
4. Igualdad entre desarrollo y produccion: Este me parece tambien muy importante porque no deberia estar bien utilizar distintas tecnologias entre desarrollo y produccion, subir un sistema a produccion tambien deberia ser algo que se deba parecer mucho al desarrollo para evitar conflictos y pequeñas incompatibilidades que pueden hacer que sea mas tardado realizar el despliegue de una aplicacion, y mas con el uso de contenedores podemos disminuir estos tiempo
